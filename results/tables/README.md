# Tables

Store publication-ready tables here in reusable formats such as CSV. Tables
should be generated from the machine-readable results in `../sem/` whenever
possible, rather than maintained as independent hand-edited values.

- `measurement_diagnostics.csv`: construct-level reliability diagnostics.
- `ad_attitude_inter_item_correlation_matrix.csv`: four-item advertising-
  attitude inter-item correlations requested during peer review.
- `ad_attitude_item_diagnostics.csv`: corrected item-total correlations and
  alpha-if-deleted values.
- `descriptive_statistics.csv`: descriptive statistics for the analyzed
  condition scores and outcome composites.
