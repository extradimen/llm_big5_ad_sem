# Figures

Store publication-ready figures generated by the analyses here. Use stable,
descriptive filenames and retain high-resolution or vector versions when
available. Figure captions belong in the manuscript or an accompanying release
note rather than inside image filenames.

Revised manuscript figures:

- `figure5_configuration_heatmap.png` — standardized paths across the four
  historical culture–model configurations;
- `figure6_configuration_forest.png` — configuration-specific association
  between ad attitude and purchase intention with 95% HC3 intervals;
- `figure7_revised_path_model.png` and `.svg` — primary observed-variable path
  model in raster and publication-ready vector formats.

Figures 5–6 are explicitly exploratory because cultural condition and LLM
backbone vary together. Figure 7 replaces the historical latent-variable diagram.
