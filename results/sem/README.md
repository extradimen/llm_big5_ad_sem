# SEM Outputs

Store machine-readable outputs from the single-group and multi-group SEM
analyses here. Recommended files include:

- `fit_indices.csv`
- `path_coefficients.csv`
- `factor_loadings.csv`
- `measurement_model.csv`
- `indirect_effects.csv`
- `group_path_comparisons.csv`

Each file should identify the model or sample to which it applies. Values in the
manuscript should be traceable to these outputs and reproducible from the final
processed dataset and SEM notebooks.
