# SEM Outputs

This directory contains the machine-readable estimates used in the revised
manuscript. Despite the historical directory name, the prespecified analysis is
an observed-variable path model rather than a reflective latent-variable SEM.

- `primary_path_coefficients.csv`: prespecified all-item path estimates.
- `primary_indirect_effects_bootstrap.csv`: prespecified indirect effects from
  2,000 run-stratified bootstrap resamples.
- `sensitivity_core_items_path_coefficients.csv`: additional two-item
  measurement-specification experiment.
- `sensitivity_core_items_indirect_effects_bootstrap.csv`: indirect effects for
  that additional experiment.
- `run_specific_path_coefficients.csv` and
  `run_specific_path_variability_summary.csv`: estimates and between-run
  summaries for both specifications.
- `post_hoc_recovered_missingness_path_coefficients.csv` and
  `post_hoc_recovered_missingness_focal_comparison.csv`: post-hoc check after
  recovering purchase-intention arrays stored under noncanonical JSON keys.
- `exploratory_configuration_path_coefficients.csv`: exploratory historical
  culture-model configuration comparisons.

All values are regenerated by `python scripts/run_all.py`.
